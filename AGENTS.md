# Repository Guidance

- The implementation is a POSIX-shell/BusyBox test harness; do not introduce a language runtime or package manager for the core analyzer.
- The executable entrypoint is `scripts/tetra-mask.sh`; it accepts exactly four files and compares all six unordered raw-byte pairs.
- `tests/run.sh` is the verification command. It uses temporary control-byte fixtures and must remain runnable with BusyBox `ash`.
- `tests/probe-ideas.sh` is an intentionally slower exhaustive narrative probe; run it with `RUN_IDEA_PROBES=1` when validating the 16-bit, Fano, decimal-cycle, and shell-semantics claims.
- `tests/probe-literals.sh` is the first-principles template check: it must remain arithmetic-free and validate only tagged fixed-width bit literals with BusyBox regular expressions.
- `docs/index.html` and `docs/agent-commons.js` are the dependency-free interactive entry **and the GitHub Pages source** (Pages serves `docs/`; a `.nojekyll` marker keeps the module and SVG raw): an `<agent-commons>` custom element, a popup book of seven spreads (cover; the E8 Coxeter projection; the Agent Commons, where eight base agents — each a sun and a planet, with its own local state — sway, by their f-mean (the global base), the 144-agent colour field they hold; the Fano converger; the tetrahedron; the two switches; open-it). It must stay import-free and CDN-free and use only relative paths, so it serves from `busybox httpd` offline and from the Pages sub-path unchanged, and it must not become a second, incompatible state engine — `nextState` is the projection of the law the probe checks. `docs/e8-step.svg` is the real proof figure (copied from the sibling `proofs/svg/e8/step.svg`), fetched and injected so its own SMIL animation and plus/minus reflection run — it is paused unless its spread is open. The canvas path is the `file://` fallback and demonstrates `DOMMatrix`. `tests/check-web.sh` is only a static API-surface check (the listed browser primitives stay present), not browser execution proof.
- `docs/commons/` is the public presentation gate, served by GitHub Pages at `/commons/`: `index.html` inlines `commons.svg` so its portal links are live and routes them to one slide per lens (hash routes, arrow keys, Esc); `commons.svg` carries its root data tree in a CDATA `<metadata id="root-data">` block and a `Prompt` script whose carrier mirrors `rosetta/src/grammar/interface.ts` inline. `views/` holds six unmodified Wikimedia Commons images; their authors and licenses (CC BY-SA 3.0/4.0, CC0, public domain) are credited on each slide and on the credits slide, and must stay credited if images change. Like the entry, it stays import-free and CDN-free (system font stacks, relative paths); opened from disk without a server it falls back to `<object>`, whose links target the top page. `tree.svg` (the second slide) is generated, not hand-edited: it is drawn by the author's private build from the Westminster Leningrad Codex (public domain), asserts every Hebrew string against the verse it cites, and carries Greek only as verse references, because the Codex Sinaiticus transcription it was checked against may not be republished.
- `tests/http11-status-literals.txt` and `tests/check-http11-status.sh` are literal protocol vocabulary checks; HTTP status codes must not be presented as authentication or trust proofs.
- `tests/check-reference-index.sh` checks the `full`/`list`/`full_list` visual frame grammar with BusyBox regular expressions; it validates shape, not applet semantics or arithmetic.
- `tests/check-16bit-buffer.sh` checks the 65,536-byte buffer invariant; this is structural self-validation, not cryptographic authentication.
- `tests/check-xor-xnor.sh` validates only the per-byte XOR/XNOR complement relation; do not expand it into an authentication claim.
- `docs/rfc-transport-notes.md` is the repository's verified boundary for RFC 4113, RFC 8085, RFC 9868, and RFC 2675; do not infer browser UDP access, discovery, or authentication from those standards.
- The analyzer must not pad or truncate unequal files. Report those edges as not comparable.
- `_archive/` is untracked historical material, not an implementation source tree. Preserve it unless the task explicitly concerns the archive, and do not infer current architecture or requirements from its contents.
- `full`, `list`, and `full_list` are optional scalable lookup-table templates: `full` and `list` are the outer views, and `full_list` contains the reversed comparison between them. Regenerate them on demand with `scripts/build-reference-index.sh`; they are not required for the core tests.
- Check `git status --short` before and after work; unrelated archive and artifact changes may be present.
